# 出装克制规则（当前版本装备体系）

装备的精确属性/被动以 equipment.md 为准，本文只给「威胁 → 装备」的映射与决策逻辑。

## 一、先判断对面威胁的类型

| 威胁类型 | 典型英雄 | 特征 |
|---|---|---|
| 物理持续输出 | 马可波罗、孙尚香、黄忠、鲁班七号、成吉思汗 | 射手/攻速普攻流，站桩或走A |
| 物理爆发切入 | 镜、兰陵王、阿轲、澜、云缨、宫本武藏 | 刺客/战士，突进秒人后撤退 |
| 法术爆发 | 妲己、安琪拉、上官婉儿、不知火舞、小乔 | 一套技能秒脆皮 |
| 法术持续/灼烧 | 周瑜、芈月、女娲、嬴政、扁鹊 | poke 消耗、持续掉血 |
| 强回复/吸血 | 程咬金、白起、扁鹊、蔡文姬、吸血流射手 | 打不死、越打越肉 |
| 高护甲/双抗坦克 | 项羽、廉颇、白起、张飞、盾山 | 平砍刮痧、技能打不动 |
| 控制链 | 张飞、东皇太一、张良、王昭君、钟馗 | 被控到死；注意东皇/张良是压制，韧性无效 |
| 百分比/真实伤害 | 典韦、末世流、痛苦面具流 | 堆生命收益下降 |
| 隐身/伏击 | 兰陵王、阿轲、裴擒虎、澜 | 消失后突然出现秒人 |

## 二、威胁 → 克制装备映射

### 被物理持续输出（射手攻速流）打崩
- **反伤刺甲**：300物防 + 反刺状态回敬35%真实伤害，射手打你等于打自己
- **不祥征兆**：受击减攻击者 20~40% 攻速 + 移速，直接废掉攻速流
- **影忍之足**：额外抵挡 6~12% 物理伤害
- **极寒风暴**：受重击时冰爆减 15% 攻速，配合冷却缩减
- 组合建议：反甲 + 不祥双圣甲是射手最恨的组合

### 被物理爆发刺客秒
- **名刀·司命**：致命伤害免死 1 秒 + 无敌，脆皮核心保命装
- **暴烈之甲**：受击叠伤害和移速，越打越强
- **冰霜冲击 / 徐行·凛冬**：+10% 韧性，受硬控后获得护盾，还有主动冰冻反打
- **贤者的庇护**：死后原地复活（每局限 2 次；20 分钟后可用原初遗珠强化位）
- 脆皮输出位：名刀/辉月优先于堆防御；肉装位：暴烈之甲 + 不祥

### 被法术爆发秒
- **魔女斗篷**：每 15 秒 400~800 法术护盾，法师爆发第一克星
- **破魔刀**（物理英雄出）：物攻转法防，输出保命两不误
- **辉月**（法师出）：主动免疫 1.5 秒，躲大招神器
- **永夜守护**：短时间掉血超 25% 触发 10% 生命回复
- 记住：法术爆发靠魔女挡第一轮，法术持续流魔女收益低

### 被法术持续/灼烧磨死
- **魔女斗篷** + **不死鸟之眼**（血量越低回复越强）+ **霸者重装**（脱战回血）
- 物理英雄：**破魔刀**；坦克：魔女 + 永夜守护

### 对面回复/吸血离谱（重伤效果，全部 -35% 回复）
- **制裁之刃**（物理/射手出）：普攻技能命中即重伤
- **梦魇之牙**（法师出）：技能命中即重伤
- **红莲斗篷**（坦克出）：灼烧范围自带重伤，贴脸就生效
- 团队有一件命中就行，别重复出

### 对面全是肉（坦克/双抗堆叠）
- 物理输出：**碎星锤**（+30%物穿）、**仁者破晓**（+15%物穿，远程翻倍到30%）、**末世**（普攻附带 7% 额外最大生命伤害）、**强者破军**（对半血以下 +30% 伤害收割）
- 法术输出：**虚无法杖**（+45%法穿）、**痛苦面具**（技能命中掉 4 次 3% 当前生命）、**日暮之流**（伤害叠法穿）、**破茧之衣**（按生命值叠法攻法穿，半肉法适用）
- 坦克互怼：**怒龙剑盾**（普攻技能附带 3.5% 最大生命伤害）

### 被控制链控到死
- **抵抗之靴**：+25% 韧性，被控队伍必出
- **冰霜冲击 / 徐行·凛冬**：+10% 韧性 + 受控护盾
- 注意：东皇太一/张良的**压制不吃韧性**，只能靠 **辉月/名刀提前开**、贤者庇护，或队友解控
- 净化（召唤师技能）可解大部分控制，但解不了压制中的伤害

### 对面真伤/百分比伤害
- 堆抗性和堆血收益都下降，改出 **名刀/辉月** 免伤类、**永夜守护**（按最大生命回复）、直接补输出换血

### 对面有隐身/绕后伏击
- **名刀·司命** 保命底线；留好位移技能；这类更多靠站位和视野，装备只能兜底

## 三、我方职业成装框架（六神装模板）

- **射手**：攻速鞋(急速战靴)/影忍之足 → 暴击流(无尽战刃+闪电匕首+宗师之力) 或 攻速穿透流(末世+仁者破晓) → 名刀/贤者收尾。对面刺客重则第二件就名刀
- **法师**：秘法之靴/冷静之靴 → 大棒过渡 → 回响之杖/博学者之怒 → 虚无法杖(对面肉) → 辉月(对面刺客) → 噬神之书(续航)
- **刺客/战士**：抵抗之靴/影忍之足 → 暗影战斧/无尽战刃 → 碎星锤/强者破军 → 名刀/贤者 + 反甲/魔女按对面伤害类型补
- **坦克**：影忍之足(对物理)/抵抗之靴(对控制) → 红莲斗篷/不祥(对物理) 或 魔女/永夜(对法术) → 霸者重装 → 按威胁补反甲/极寒风暴
- **辅助**：游走装(学识宝石→极影系=输出型游走 / 近卫系=坦辅型游走) → 抵抗之靴 → 团队装(旭日初光、冰霜冲击、救赎类)
- 出装顺序通则：**鞋 → 核心输出/核心防御 → 按对面最痛的威胁补克制装 → 保命装收尾**

## 四、特殊规则（避免给出违规建议）

1. **鞋类移速不叠加**，只买一双；后期可卖鞋换第六件大装
2. **打野刀系**（狩猎宽刃→游击弯刀/巡守利斧→追击刀锋/符文大剑/巨人之握/贪婪之噬）只有带惩击才有收益，非打野别推荐
3. **游走装**（学识宝石→极影/近卫系列）是辅助/游走位专属机制，吃线收益会被惩罚，非辅助别推荐
4. **元流结晶 → 无象神器**：按职业选对应版本（战士/刺客/射手/法师/坦克/坦辅/法辅），被动围绕大招触发，是当前版本核心大件
5. **贤者的庇护**每局只能复活 2 次；**原初遗珠** 20 分钟后才开放购买
6. 免死类装备（名刀/辉月/贤者）可以共存但注意冷却期空窗，别同时依赖
7. **专属装备**只有对应英雄能用：项羽-破城霸王戟、刘邦-斩蛇赤霄、张飞-震军虎啸、干将莫邪-太古剑冢、大乔-沧海明珠

## 五、局势修正

- **顺风**：优先补输出滚雪球，保命装可以延后一件
- **逆风**：提前出克制装和保命装，六神装梦想让位于「下一波团不被秒」
- **经济不足**：推荐可过渡的小件（如先出 匕首/搏击拳套 过渡攻速，红玛瑙/布甲 过渡防御），小件要能合成目标大件，不浪费经济
- 对面「难搞英雄」优先级 > 泛泛的阵容克制：先解决让用户最难受的那个人
