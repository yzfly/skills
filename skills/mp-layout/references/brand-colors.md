# 品牌色候选（按主题）

规则：全文只用一个彩色。选一个能代表账号「人设」的色，长期不换。每个主题给三个，附气质，按文章调性挑。

| 主题 / 调性 | 色 1 | 色 2 | 色 3 |
|---|---|---|---|
| 清新自然（默认） | 松绿 `#2F6F5E` 沉稳 | 苔绿 `#5B8C5A` 温和 | 湖蓝绿 `#2A9D8F` 明快 |
| 认知 / 成长 / 方法论 | 藏蓝 `#1F3A5F` 理性 | 靛蓝 `#3D5A80` 可信 | 石墨蓝 `#2B4C7E` 稳重 |
| 情感 / 生活 / 随笔 | 砖红 `#B5533C` 温暖 | 赭橙 `#C97B3A` 亲切 | 豆沙 `#A8646A` 柔和 |
| 商业 / 财经 / 职场 | 墨黑 `#1A1A1A` 克制 | 深棕 `#5C4033` 老派 | 深青 `#0F4C5C` 专业 |
| 科技 / AI / 工具 | 钴蓝 `#0047FF` 锐利 | 电紫 `#5B4BFF` 前沿 | 青碧 `#0FA3B1` 清爽 |
| 文化 / 阅读 / 历史 | 朱砂 `#8C2F39` 典雅 | 黛青 `#3B5B6E` 书卷 | 赭石 `#8B5E34` 古朴 |
| 健康 / 育儿 / 家庭 | 珊瑚 `#E07A5F` 活力 | 麦黄 `#D4A24C` 暖心 | 薄荷 `#3FA796` 安心 |

选色后检查：在白底上作为 20px 粗体标题是否清楚；作为 16px 正文加粗是否仍可读（对比度不足就换深一档）。
