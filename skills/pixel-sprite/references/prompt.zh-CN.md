# 像素精灵 · 生成提示词模板（中文）

把 `【主体】` 替换为主体特征卡；`32x32`、`6-8 种`、`纯白背景` 按用户参数替换。其余约束原样保留。

```text
将参考图中的【主体】转换为低分辨率像素插画（Low Resolution Pixel Sprite）。

保持参考图中主体的原始设计，包括整体造型、比例、轮廓、结构、姿态、颜色特征和识别元素完全一致。不要重新设计主体，不改变原有设计语言，仅将表现形式转换为经典手工像素艺术。

生成具有复古游戏感的像素图标（Pixel Icon / Sprite Asset）。

采用 32x32 Pixel Sprite 规格，基于严格的 1 Pixel Grid 进行绘制。所有像素保持统一正方形比例，使用 Nearest Neighbor 像素放大逻辑，保持清晰硬边像素效果。避免模糊像素、抗锯齿、渐变过渡、像素滤镜和自动像素化效果。

根据主体特点转换为简洁的像素结构，使用清晰明确的轮廓（Clear Silhouette），保持高识别度（High Readability）。通过干净连续的像素色块（Clean Pixel Clusters）表达结构，避免零散像素和复杂细节。

采用有限色板（Limited Palette），控制在 6-8 种主要颜色以内。使用纯色块和简单的一到两级明暗关系表现体积，不使用复杂光影，不使用渐变。

整体采用经典 8-bit / 16-bit 游戏 Sprite 设计语言，具有可爱、温暖、怀旧、舒适且充满活力的视觉氛围。

输出为单个【主体】像素风格，保持居中构图，纯白背景，无文字，无 Logo，无边框，无额外装饰，无环境元素。
```

## 主体特征卡示例

```text
【主体】：
类别：一只橘色短毛猫
造型与比例：圆脸大头，头约占全身 1/2，身体蜷成一团，整体近似横向椭圆
姿态与朝向：正面趴卧，双前爪并拢露在身前，尾巴从右侧绕到身前
主色：橘黄（#F2A03D）、奶白（腹部与嘴周）
辅色与明暗：深橘（#C9732A）作条纹与暗部，粉色小鼻子
识别元素：额头 M 形深色条纹、左耳缺一个小口、绿色眼睛
必须保留：M 形条纹、左耳缺口、蜷卧姿势
```

## 参数替换速查

| 用户说 | 替换 |
|---|---|
| 「小一点 / 做 favicon」 | `16x16 Pixel Sprite`，色板降到 4-6 种 |
| 「大一点 / 要更多细节」 | `64x64 Pixel Sprite`，色板可放宽到 10-12 种 |
| 「透明背景」 | `纯白背景` → `透明背景（PNG alpha）`；宿主不支持透明时保持纯白并告知 |
| 「深色背景 / 品牌色背景」 | `纯白背景` → `纯色 <颜色名> 背景`，仍然无环境元素 |
| 「做一套 / 多个」 | 每个主体单独一张，特征卡分别写，技术约束段落原样共用 |
