# 为一个产品建立用词表

用词混乱是界面「不专业」的第一来源：同一个东西三个名字，同一个动作两个动词，内部代号漏到界面上。改文案前先有一张用词表，改的时候按表替换，改完全站一致。

依据：Semi「保持一致」（行业术语、平台术语、名词动词统一）；Ant「表述一致」；Arco「词汇统一」；M「一个功能里用同一个动词」；Apple「维护一份标准术语表」；Pod「voice chart 的 vocabulary 一行」；MC「不要为同一个东西换同义词」。

---

## 一、谁的话

界面说**用户在工作里说的话**，而不是：

- 开发团队的话：接口、字段、节点、落盘、回调、缓存。
- 产品团队内部代号：项目代号、模块内部名、架构图上的名词。
- 模型 / 算法的话：探针、投影、召回、embedding、温度（除非用户就是调参的人）。

检验：拿去问一个真实用户「这个词你平时怎么叫」。问不到人，就看下一步的调研。

NNg 的提醒：用户每天在用的专业词对他们不算黑话（坐席、外呼、意向等级）；团队内部的词才是。

---

## 二、调研：看行业和大厂怎么叫

对每个拿不准的概念，查三类来源，取多数叫法：

1. **用户正在用的同类产品。** 他们每天看的界面决定了他们的词汇。国内 B 端优先看腾讯云、阿里云、火山引擎 / 字节、百度智能云的控制台和官方文档；大模型平台看腾讯云智能体开发平台、扣子 / 扣子罗盘、火山方舟、百炼；办公协作看飞书、钉钉、企业微信。
2. **行业官方文档和标准。** 呼叫中心、医疗、金融、电商各有通行叫法（如外呼行业的「通话记录」「坐席」「意向识别」）。
3. **开源产品的 i18n 文件。** 最直接的一手界面字符串：GitHub 上搜产品仓库的 `zh-CN.json` / `locales/zh`。例如扣子罗盘 `coze-dev/coze-loop` 的 `frontend/packages/loop-base/loop-lng/src/locales/*/zh-CN.json`。

操作步骤：

1. 从代码和页面里列出所有名词和动词（按钮、标题、状态、菜单）。
2. 找出「同物异名」和「内部词」。
3. 每个词搜：`site:cloud.tencent.com <概念>`、`site:docs.coze.cn <概念>`、`site:help.aliyun.com <概念>`、产品帮助中心。记下原文和 URL。
4. 取多数叫法；多家不一致时，取用户最常用的那家；仍不定就选最短、最不需要解释的。
5. 同名冲突时（两个不同东西都想叫「开场白」），给次要的那个换名（「开场环节」），并在表里写清。

## 三、用词表格式

```markdown
| 不用 | 用 | 说明 / 出处 |
|---|---|---|
| 话单 | 通话记录 | 百度客悦、腾讯云联络中心文档都叫通话记录 <URL> |
| 测试集 | 评测集 | 腾讯云智能体开发平台、扣子罗盘 <URL> |
| 回退 | 还原到此版本 | 腾讯云「还原到调试态」 <URL> |
| 同步到正式环境 | 发布到正式环境 | 状态：待发布 / 已发布 |
```

再加三块：

- **动作词表**：新建 / 添加 / 删除 / 移除 / 保存 / 发布 / 导入 / 导出 / 启用 / 停用 各指什么，不混用。
- **状态词表**：每个流程一组 `待 X / X 中 / 已 X / X 失败`。
- **保留不改**：行业词、专名、品牌名（不要把用户熟悉的行业词「翻译」成大白话）。
- **仅管理员可见**：技术配置页可以保留的技术词。

用词表放进仓库（如 `docs/界面文案规范.md`），在代码评审时对照。

## 四、通用动作词（Semi / Ant 口径）

| 用 | 不用 | 说明 |
|---|---|---|
| 新建 | 创建（二选一，全站统一） | 从无到有 |
| 添加 | 新增 | 把已有的放进来 |
| 删除 | 清除 | 没了 |
| 移除 | — | 从集合里拿出，东西还在 |
| 启用 / 停用 | 开启 / 暂停 / 开始使用 | 开关类功能 |
| 登录 / 退出登录 | 登陆 / 注销（除非真的是注销账号） | |
| 账号 | 帐号 | |
| 其他 | 其它 | |
| 你 | 您 | 除非产品已定用「您」 |
| 抱歉 | 对不起 | 只在系统出错且后果严重时 |
| 了解更多 / 了解 X | 查看更多 | Semi：不用感官动词 |
| 禁用名单 / 允许名单 | 黑名单 / 白名单 | 包容性语言 |

## 五、改名的连带清单

改一个词不只改一处：

- 按钮、标题、菜单、面包屑、Tab
- 空状态、Toast、确认弹窗、报错
- tooltip、帮助文档链接文字
- 后端返回的 message
- 邮件、短信、通知模板
- 导出文件的表头和文件名
- i18n 其他语言
- 埋点显示名（不改事件键）

改完 grep 旧词，确认只剩「不能动的字」（见 SKILL.md）。
