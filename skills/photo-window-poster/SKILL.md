# 几何情绪窗口海报 · Photo Window Poster

提示词原作者：小小东（XXD）。本 Skill 把这段提示词封装为可复用的工作流：读图 → 定窗口 → 定配色 → 提炼文案 → 生成 → 质检。

## 版式铁律

| 项目 | 规则 |
|---|---|
| 画幅 | 3:4 竖版；上下两区高度**严格 1:1**，各占 50% |
| 上半 | 原始照片：主体结构、真实质感、自然光影、原有色彩氛围全部保留；只做轻微高级摄影调色（高端品牌广告 / 艺术杂志 / 展览视觉质感）；为适配画幅可自然扩展天空、地面、环境，**主体本身不动** |
| 下半 | 提取最具识别性的主体、轮廓、姿态与叙事关系，重构为极简视觉海报；核心语言「真实物象穿越几何情绪窗口」 |
| 窗口 | 一个窄长、克制、低饱和的几何色块，作为视觉锚点与空间容器；方向不固定——横向 / 竖向 / 斜向，由主体重心、动作方向、轮廓走势与版面节奏决定 |
| 主体 | 以真实摄影感或精致写实方式进入色块，并局部越界、破框、伸出或穿过边界；单一焦点，可居中、偏心、纵向生长或横向舒展 |
| 背景 | 白、浅灰或极浅暖色；可加极轻微的文化纹样、线性图形、地形线、水波线、光影轮廓或抽象符号作为若隐若现的辅助层 |
| 配色 | 从上方照片提取最有辨识度、最有精气神的颜色关系 → 浅色几何窗口 + 真实主体色彩 + 极少量中性色排版；窗口色柔化为雾蓝、浅青、米白、淡粉、暖灰、浅金等与原图气质一致的浅色 |
| 文字 | 从主题、情绪、动作、状态或象征意义提炼一个简短标题（中文或英文，跟随用户），配少量副标题、地点、状态词、微型注释；标题可横排、竖排或沿色块与主体关系排布；辅助信息小字号、细字重、舒展字距 |
| 气质 | 东方留白、现代秩序、自然生命力、高级商业美感；无论人物、动物、植物、建筑、器物、食物、交通工具或自然景观，都保持真实摄影与几何窗口之间清晰、优雅、可迁移的呼应 |
| 输出 | 每张照片单独一张，不多图拼接 |

## 工作流

### 1. 读图

对每张照片写四行：主体是什么、轮廓与姿态走势（竖直 / 水平 / 斜向 / 蜷曲）、画面里最有精气神的 2–3 个颜色、一句叙事关系（谁在做什么 / 处于什么状态）。

### 2. 定窗口

按轮廓走势选色块方向：竖直主体（人、塔、树）→ 竖向窄条；水平主体（船、桥、卧姿动物）→ 横向窄条；有明确动势 → 顺动势斜向。决定主体从哪一边越界（顺着动作方向或生长方向）。

### 3. 定配色与文案

- 窗口色 = 照片主色柔化一档（降饱和、提亮）；写出色名与近似 HEX。
- 标题 ≤ 6 个汉字或 ≤ 4 个英文词；副标题 / 地点 / 状态词各 ≤ 1 行。文案语言跟随用户，未说明则中文标题 + 英文小字。

### 4. 生成

把 `references/prompt.zh-CN.md`（或 `prompt.en.md`）的完整提示词，与第 1–3 步的具体判断（主体、窗口方向、越界方式、窗口色、标题文案）一起交给图像模型，**必须附原照片走图生图 / 编辑模式**，上半区域不允许重绘。没有图像工具时交付完整提示词与判断结果。

### 5. 质检

| # | 检查 | 不过 → 修 |
|---|---|---|
| 1 | 上下严格 1:1，3:4 | 强调「上下两个区域高度严格 1:1」 |
| 2 | 上半主体与原图一致，仅轻微调色 | 强调「主体本身保持不变，仅轻微高级调色」 |
| 3 | 只有一个几何色块、低饱和、窄长 | 删多余色块，降饱和 |
| 4 | 主体确实越界 / 破框 | 强调「局部越界、伸出或穿过边界」 |
| 5 | 大面积留白，单一焦点 | 删辅助元素 |
| 6 | 配色与照片同源、整体轻盈 | 从照片重新取色 |
| 7 | 文字克制、层级清楚、无错字 | 减字，重排 |
| 8 | 每张单独输出 | 拆图 |

### 6. 交付

每张图：成品 + 一行说明（窗口方向与颜色、主体越界方式、标题）+ 最终提示词（代码块）。多张时逐张交付，风格保持一致。
