# 呼吸感品牌全案 · 规范模板（brand.md）

把方括号替换成品牌实际内容。每一节都是交付物的一部分，不要删节。

## 一、定位三行

```text
🟦 品牌 / [英文名] [中文身份，如「全球创新者社区」]
🟦 定位 / [词一] · [词二] · [词三]
✔️ 洞察：[为什么现在的视觉显得廉价 / 为什么需要呼吸感，一两句人话]
```

示例：

```text
🟦 品牌 / GLOBAL READY 全球创新者社区
🟦 定位 / 出海 · 极简 · 链接
✔️ 洞察：出海第一步，审美不能输。很多品牌出海看起来有「廉价感」，其实是因为视觉太满、太乱。我们要做的，是帮你在全球市场建立 3 秒钟的顶级信任感。
```

## 二、色彩 token（全案只有三个色）

| token | 值 | 用途 |
|---|---|---|
| `--brand` | `[#HEX]` [色名] | 唯一彩色：色块、线条、Emoji、按钮 |
| `--paper` | `#FAFAF7`（或 `#FFFFFF`） | 背景、留白 |
| `--ink` | `#1A1A1A` | 正文、小字、线条的黑色版本 |

**出海安全色**（按行业与性格选一个）：

| 色名 | HEX | 气质 | 常见行业 |
|---|---|---|---|
| 钴蓝 Cobalt | `#0047FF` | 可信、国际、链接 | 社区、SaaS、金融科技 |
| 克莱因蓝 Klein | `#002FA7` | 艺术、笃定 | 设计、文创、时尚 |
| 国际橙 Intl. Orange | `#FF4F00` | 活力、行动 | 消费品、户外、创业 |
| 信号绿 Signal Green | `#00C853` | 增长、健康 | 可持续、健康、农业 |
| 正红 True Red | `#E60012` | 热烈、决断 | 食品、文化、节庆 |
| 墨黑 Ink | `#111111` | 克制、奢侈 | 高端制造、精品 |

规则：不允许渐变；不允许第二个彩色；主色必须能在白底上通过 AA 对比度（文字用）或作为大色块（非文字用）。

## 三、字体与字号

| 角色 | 字体 | 字号（相对） | 用法 |
|---|---|---|---|
| Display | [Inter / Helvetica Now / Söhne] Bold | 1 | 首屏标题、帆布袋大字，全大写 + 字距 +2% |
| Heading | 同上 Medium | 0.5 | 版块标题 |
| Body | 同上 Regular | 0.22 | 正文 |
| Micro | 同上 Regular / Mono | 0.14 | 元数据、编号、网址，字距 +8% |

中文：思源黑体 / 苹方，字重对齐；不混第三种字体。

## 四、留白硬指标

| 版面 | 主色块 | 留白 | 内容 |
|---|---|---|---|
| 独立站首屏 | ≤ 40% | ≥ 45% | ≤ 15% |
| 社媒封面 | ≤ 35% | ≥ 50% | ≤ 15% |
| 名片 | ≤ 50%（一面满色） | ≥ 40% | ≤ 10% |
| 帆布袋 / 周边 | 单线或单字，≤ 20% | ≥ 80% | — |

## 五、线条链接母题

- 线宽：画布短边的 0.6%–0.8%，圆头圆角。
- 形态：一根连续单线，从节点 A 出发，经 2–3 次平滑转折到节点 B；节点为实心圆，直径 = 线宽 × 3。
- 颜色：`--brand`，在主色块上用 `--paper`。
- 场景：logo 辅助图形、首屏背景一根线、名片背面一根线、帆布袋一根线贯穿。
- 禁止：交叉网格、多线并行、渐变描边、3D 管道、粒子。

## 六、线条 Emoji 表情集（8 个）

统一：一个圆（直径 = 线宽 × 24）+ 2–4 笔，同线宽、同圆头，`--brand` 或 `--ink` 单色。

| # | 名称 | 画法 |
|---|---|---|
| 1 | 微笑 Smile | 两点眼 + 一条上弯短弧 |
| 2 | 眨眼 Wink | 一点眼 + 一条短横 + 上弯弧 |
| 3 | 惊喜 Wow | 两点眼 + 一个小圆嘴 |
| 4 | 思考 Hmm | 两点眼 + 一条平短线 + 圆外右上一个小圆（气泡） |
| 5 | 点赞 Nice | 圆内一只极简竖起拇指（3 笔） |
| 6 | 挥手 Hi | 两点眼 + 弧嘴，圆外右侧一只三指小手 |
| 7 | 星星眼 Star | 两个四角星 + 上弯弧 |
| 8 | 打盹 Zzz | 两条下弯短弧眼 + 圆外右上「z z」 |

```text
拒绝廉价感！[品牌名] 的高级呼吸感全案

🟦 品牌 / [英文名] [中文身份]
🟦 定位 / [词一] · [词二] · [词三]
✔️ 洞察：[洞察一两句]

🎨 设计逻辑：
🔵 高纯度色块 + 留白：[主色名]作为唯一色彩，[留白比例]的呼吸感，[一句这个品牌为什么配得上这种克制]。
🔗 线条即链接：[这个品牌里「链接」的具体含义，如人与组织 / 用户与产品]，一根流动的线贯穿所有物料。
🙂 灵动 Emoji：8 个线条表情，[用在哪：社媒互动 / 贴纸 / PIN]，让 [行业] 也有温度。

💼 实战落地：[物料一] · [物料二] · [物料三] · [物料四] · [物料五] · [物料六]，同一套视觉语言。
```
