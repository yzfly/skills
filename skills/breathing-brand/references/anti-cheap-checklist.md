# 反廉价感审查清单（出稿前逐条过）

| # | 检查项 | 不过关的典型表现 | 修正 |
|---|---|---|---|
| 1 | 全案只有三个色 | 出现渐变、第二个彩色、彩色阴影 | 删到只剩主色 / 纸白 / 深灰 |
| 2 | 主色是高纯度的 | 主色偏灰、偏粉、偏「莫兰迪」 | 回到出海安全色表选一个 |
| 3 | 留白达标 | 任一版面留白 < 45%（周边 < 80%） | 删元素，不缩小元素 |
| 4 | 只有一种图形语言 | 线条之外还有几何装饰、粒子、光效、纹样 | 只保留那一根线 |
| 5 | 线条是连续单线 | 线条交叉成网、多线并行、断成虚线 | 重画为一根线 + 两个节点 |
| 6 | 字体 ≤ 2 套、字号 ≤ 4 级 | 出现第三种字体、装饰字体、字号超过四级 | 回到 Display / Heading / Body / Micro |
| 7 | 标题短 | 首屏标题超过 5 个英文词 / 8 个汉字 | 砍到一句 |
| 8 | 无 3D、无玻璃拟态、无光泽 | 立体 logo、玻璃卡片、金属高光 | 全部拍平 |
| 9 | 无满版摄影与库存人像 | 首屏铺满 stock photo、笑脸团队照 | 换成色块 + 线条 |
| 10 | Emoji 与线条同一线宽 | 表情比线条粗 / 细、风格不一致 | 统一线宽与圆头 |
| 11 | 物料之间同一套语言 | 名片、帆布袋、网站各自为政 | 用同一个主色、同一根线、同一字体重做 |
| 12 | 三秒测试 | 把首屏缩到拇指大小，3 秒内认不出品牌名和主色 | 加大留白、加大标题、减少一切其他 |

通过标准：12 项全部通过。任一项不过，先修再交付，并在交付末尾写明「修正了第 N 项：……」。
